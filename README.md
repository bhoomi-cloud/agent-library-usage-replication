# Agent Library Usage Replication

This repository contains the code used for my MSc dissertation replication and extension of the study "A Study of Library Usage in Agent-Authored Pull Requests."

The replication investigates library usage in agent-authored pull requests using the AIDev dataset.

The original study investigates:
- RQ1: Library usage in agent-authored pull requests
- RQ2: New dependencies introduced by agents
- RQ3: Libraries selected by agents

This project also includes an extension:
- RQ4: Comparison of library usage and acceptance between merged and unmerged pull requests.

The final analysis focuses on C#, Go, Python, and TypeScript.

The Jupyter notebook in this repository contains the implementation and analysis.
